# Brand Asset Dashboard

A small example app built with [`@adobe/react-spectrum`](https://react-spectrum.adobe.com/) that
demonstrates a brand asset management dashboard.

The header includes a **Dark mode** [`Switch`](https://react-spectrum.adobe.com/react-spectrum/Switch.html)
that toggles the app-wide `Provider` `colorScheme` between `light` and `dark`.

## Getting started

```bash
yarn install
yarn dev
```

Then open the printed local URL (defaults to http://localhost:4321).

## Scripts

- `yarn dev` – start the Vite dev server
- `yarn build` – type-check and build for production
- `yarn preview` – preview the production build
